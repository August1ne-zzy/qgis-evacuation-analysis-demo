QGIS Evacuation Analysis Demo

This repository presents a coursework project using QGIS to analyze evacuation facilities, tsunami inundation areas, and population data.

Overview

In this project, I used QGIS to combine multiple geospatial datasets and visualize the relationship between tsunami inundation risk, evacuation facilities, and local population distribution.

The main goal was to estimate and visualize the evacuation population for each evacuation facility.

Tools

QGIS

GIS data processing

Choropleth map creation

Spatial data overlay

Data used

The analysis used the following types of data:

Evacuation facility data from the National Land Numerical Information Download Service

Tsunami inundation assumption data

2020 Population Census data for Kanagawa prefecture at the town-block level

The original data files are not included in this repository because of file size and coursework restrictions.

Analysis process

Imported evacuation facility data, tsunami inundation area data, and population data into QGIS.

Adjusted layers and coordinate reference systems.

Overlaid the datasets to examine the relationship between evacuation facilities and affected population areas.

Created a classified map showing evacuation population by facility.
